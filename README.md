# 🪔 Diwali Sales Data Analysis

## 📊 Overview
This project performs Exploratory Data Analysis (EDA) on Diwali sales data to uncover customer purchasing behavior, trends, and key business insights. The goal is to help businesses understand their target customers and improve marketing strategies during festive seasons.

---

## 🎯 Objectives
- Analyze customer demographics and purchasing patterns  
- Identify top-performing product categories and regions  
- Understand factors influencing sales (gender, age, occupation, etc.)  
- Provide actionable business insights  

---

## 🛠️ Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## 📂 Dataset
- Dataset contains **11,000+ records** and 15 features  
- Includes customer details like:
  - Gender, Age, Marital Status  
  - State, Occupation  
  - Product Category  
  - Orders and Sales Amount  

---

## 🔍 Data Cleaning
- Removed null and irrelevant columns (`Status`, `unnamed1`)  
- Handled missing values  
- Converted data types for accurate analysis  
- Standardized dataset for consistency  

---

## 📈 Key Analysis Performed

### 👩 Gender Analysis
- Majority of buyers are **female**  
- Female customers contribute higher total sales  

### 🎂 Age Group Analysis
- Highest purchases from **26–35 age group**  
- Female customers dominate this segment  

### 🌍 State-wise Analysis
- Top states by sales:
  - Uttar Pradesh  
  - Maharashtra  
  - Karnataka  

### 💍 Marital Status
- **Married women** have higher purchasing power  

### 💼 Occupation
- Top contributing sectors:
  - IT  
  - Healthcare  
  - Aviation  

### 🛍️ Product Category
- Most popular categories:
  - Food  
  - Clothing  
  - Electronics  

---

## 📊 Key Insights
- Target audience:  
  👉 Married women aged 26–35  
  👉 Located in major states like UP, Maharashtra, Karnataka  

- High-performing segments can be targeted for:
  - Marketing campaigns  
  - Personalized offers  
  - Seasonal promotions  

---

## 📌 Conclusion
This analysis highlights how demographic and behavioral data can drive smarter business decisions. Companies can use these insights to improve customer targeting, increase sales, and optimize marketing strategies during festive seasons.
